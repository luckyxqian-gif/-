# 信息体系与表达

## 先形成完整体系

先回答“这份交付要帮助读者完成什么”，再决定写哪些内容。围绕目标建立一条能够解释全貌的主线，让各部分形成真实的层级、因果、对照、演进或应用关系。

不设置固定模块数、目录数、卡片数、表格数或判断句数量。卡片、表格、链条、关系图和折叠区只是体系内部的表达工具，不能把连续内容切成彼此孤立的信息点。

页面篇幅受限时，先删除或降低与目标关系较弱的内容。保留下来的关键内容必须充分表达；不能用缩小字号、压紧行距、删去必要解释或把重点藏入折叠层来通过限制。

## 每个板块都落实主次

先按主题自身逻辑划分真实板块，例如阶段、问题、对象、关系或任务；名称完全由本次内容决定。不要把内部阅读判断另做成“必须知道”“需要理解”“按需查看”等可见栏目。

每个板块都完成同一套编辑判断：

1. 先给完成本次目标不可缺少的新结论。即使读者原本不了解主题，也不能省略或藏入折叠区。
2. 再解释读者理解该结论所需的概念、关系、机制与必要背景，使其真正明白“为什么”，但不扩写成教科书。
3. 最后才把精确数据、统计口径、补充背景、次要案例、边界情况和延伸说明放入低干扰位置或展开层。会改变核心判断的限定仍须留在正文。

成品只呈现主题内容本身，不呈现上述编辑步骤、阅读层级名称或 Agent 的取舍说明。

## 主次与密度

- 用顺序、版面面积、字号、粗细、留白和关系位置表达重要程度，颜色只表达功能。
- 系统重点只标最小必要词组或最小结论单元。通过删除测试：去掉标记后如果仍能同样快地抓住重点，就继续减少标记。组件名称、场景标签、栏目提示和其他通用引导语不因版式身份而加粗或高亮；强调落在真正改变理解、结论或行动的知识词与判断上。
- 次要内容不必统一涂灰；降低面积、字号或进入展开层即可。待核实、口径差异和状态提醒可以使用弱化样式。
- 高密度意味着去掉重复和低增量表达，不等于牺牲事实、限定、例外或因果链。
- 正文优先呈现大、小、强、弱、上升、下降、成熟、变化中等可理解评价。精确数字只有在会改变判断时进入正文，其余进入低干扰的补充层。

## 知识总结的重点呈现

知识总结、复习资料、学习说明或需要反复调用的专业说明，不能只靠段落顺序暗示重点。先在每个真实知识板块中判断是否存在读者需要快速调出的规则、结论、数字、例外、易混边界或行动判断；存在时，必须选出最小必要内容并做静态重点呈现。没有真实重点时，不为凑样式强行标记。

强调方式服务于这份内容的阅读动作，而不是把“短术语”“规则名称”“数字”等类别绑定给某一种样式。可以使用粗体、文字色、淡色底、划线、左侧色条或结论框；一个点需要同时被快速定位和准确记忆时，可以复合使用两种样式。选择时看读者为什么需要停在这里：它是关系锚点、可直接复述的结论、容易混淆的边界，还是会影响行动的风险。

真正会导致错误结论、行动失误或时点误判的内容，可以单独使用 `critical-note` 结论框；框内仍只突出一句可直接复述的判断。不要把整段同时加粗、染色和铺底，也不要把组件名、场景标签、导航或泛泛的提示语做成重点。重点应分布在各自所属的知识位置，而不是集中堆在页首或摘要区。

## 文案

- 结论写成读者能够直接复述的自然句，不用抽象术语冒充判断。
- 一句话承担一个主要意思；长解释按逻辑断句，不机械执行固定字数。
- 术语首次出现时附最短、贴合当前主题的白话解释。
- 使用直接、具体的语言，避免空泛宣传语和重复总结。
- 成品不出现面向 Agent 的执行过程。真正帮助读者使用内容的简短提示可以保留。
- 未核实事实清楚标注状态；预测与事实分开，不把推断写成已经发生的结果。

## 标题、导读与时间

- 标题足以说明内容时，使用轻量页头并直接进入正文。
- 主题跨度大、知识密度高时，才增加极短导读或总判断。
- 导航前后的内容均由本次目标和逻辑关系决定。可以出现任何确有必要的内容，也可以省略整块区域；不得把参考页或能力示例里的结构当成固定清单。
- 显示“本次交付时间”。内容有独立资料时点时，另外显示资料截至时间；两者不能混写。
- 使用本次专属信息，不使用模板化口号、标签墙、封面图或装饰性元信息。

## 参考文献

末尾使用“参考文献”或“资料来源”，只列实际使用的来源及其支持内容。正文可以保留不抢眼的就近来源标记，完整信息统一放在末尾。

参考文献不包含 Agent 的分析过程、检索记录、证据矩阵、设计理由、验证过程或后续计划。
